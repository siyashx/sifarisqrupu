# Ələhbərdə ortaq alqı-satqı və lotoreya — 2.1.5 (30)

Lotoreyanın canlı dəvəti və nəticələri artıq ZAKAZ və ELEHBER cihazlarına ayrı-ayrı göndərilir. Üzvlük və bilet cədvəlləri ortaq qalır. Elan bildirişləri də mənbə tətbiqindən asılı olmayaraq hər iki tətbiqə gedir; alqı-satqıda offline müştərilər də bildiriş ala bilir, göndərən/disable/mute filtrləri qorunur. ELEHBER qeydiyyatı da rədd edilmiş token üçün tokenRefreshRequired cavabı alır; müştəri yeni tokenlə qeydiyyatdan keçir. iOS lotoreya alert-i chime.caf istifadə edir.

Dəyişən mənbələr: LotteryService, PushController, PushAudienceService, FcmPushService. Yeni cədvəl/env tələb olunmur. Push/lotoreya üzrə 89 test keçdi. VPS deployu edilməyib; yenilənmiş backend deploy edilməlidir. Admin panelində əlavə dəyişiklik lazım deyil.
