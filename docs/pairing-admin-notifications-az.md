# Cütləşmə mərhələsi hazır olduqda admin bildirişi

Mərhələdə bütün oyunların hesabları təsdiqlənəndə yarışı yaradan adminin qoşulmuş cihazlarına “Növbəti mərhələ hazırdır” bildirişi yaradılır. Son final üçün bu bildiriş göndərilmir. Bildirişə toxunmaq həmin yarışın idarə səhifəsini açır.

Eyni hazır mərhələ üçün bildiriş təkrar göndərilmir. Admin nəticəni sıfırlayıb yenidən təsdiqlədərsə yeni hazır mərhələ bildirişi yaradıla bilər. Bu imkan üçün backend deploy olunmalı və bildiriş kanalı ilə yönləndirmə üçün admin Android tətbiqi yenidən build edilməlidir.
